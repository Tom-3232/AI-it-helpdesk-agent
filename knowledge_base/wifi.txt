=== Wi-Fi Connectivity Troubleshooting Guide ===

Problem Overview:
Wi-Fi connection drops, fails to obtain an IP address, or shows 'Connected, no internet'.

Step 1: Check physical adapter status
- Ensure Wi-Fi toggle on your laptop or keyboard switch is switched ON.
- Open Network Settings: Go to Settings > Network & Internet > Wi-Fi. Ensure Wi-Fi is toggled on.

Step 2: Forget and Reconnect to Network
- Click on the Wi-Fi icon in the taskbar.
- Right-click your corporate/home Wi-Fi SSID (e.g. 'Company-Corp' or 'Home-WiFi') and click 'Forget'.
- Turn off Wi-Fi for 5 seconds, turn it back on, select your network, and re-enter credentials.

Step 3: Run Windows Network Diagnostics & Reset TCP/IP Stack
- Open Command Prompt as Administrator.
- Execute the following network reset commands in order:
  1. ipconfig /release
  2. ipconfig /flushdns
  3. ipconfig /renew
  4. netsh winsock reset
  5. netsh int ip reset
- Reboot your PC after running these commands.

Step 4: Check IP configuration
- Run `ipconfig /all`. Ensure DHCP is enabled and your IP starts with a valid range (e.g., 192.168.x.x or 10.x.x.x). If it starts with 169.254.x.x, your laptop failed to reach the DHCP server.

Step 5: Router / Access Point power cycle
- If working from home, unplug the power cable of your modem/router, wait 30 seconds, and plug it back in.

If Wi-Fi still fails to connect after these steps, request a hardware diagnostic or submit an IT support ticket for IT administrator assistance.
