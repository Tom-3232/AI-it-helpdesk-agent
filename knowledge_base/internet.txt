=== Internet & Network Reachability Guide ===

Problem Overview:
Ethernet or Wi-Fi shows connected, but webpages fail to load or DNS resolution fails.

Step 1: Verify General Connectivity
- Open Command Prompt and test reaching public DNS: `ping 8.8.8.8`
- If pinging 8.8.8.8 succeeds but `ping google.com` fails, your issue is DNS resolution.

Step 2: Change DNS Servers
- Open Network Connections (Win + R -> `ncpa.cpl`).
- Right-click your network adapter (Ethernet or Wi-Fi) -> Properties.
- Double-click 'Internet Protocol Version 4 (TCP/IPv4)'.
- Select 'Use the following DNS server addresses':
  - Preferred DNS: 1.1.1.1 or 8.8.8.8
  - Alternate DNS: 1.0.0.1 or 8.8.4.4
- Click OK and test opening a web page.

Step 3: Clear Browser Cache and Cookies
- Chrome / Edge: Press Ctrl + Shift + Delete.
- Select 'All time' as range, check 'Cookies and other site data' and 'Cached images and files'.
- Click Clear data.

Step 4: Check Proxy Settings
- Go to Windows Settings > Network & Internet > Proxy.
- Ensure 'Automatically detect settings' is enabled, and 'Use a proxy server' is toggled OFF unless specifically instructed by corporate IT.

Step 5: Disable Third-Party Security Software / Firewalls temporarily
- Antivirus firewalls can sometimes block outgoing traffic. Temporarily disable third-party firewalls to test reachability.
