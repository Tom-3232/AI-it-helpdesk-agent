=== Printer Troubleshooting Guide ===

Problem Overview:
Printer is offline, jobs are stuck in queue, or documents fail to print.

Step 1: Check Physical and Network Connections
- Ensure the printer is powered on and connected via USB or to the same Wi-Fi/Ethernet network as your computer.
- Check printer paper tray, ink/toner levels, and error lights on the printer display panel.

Step 2: Clear Print Spooler Queue
- Open Run dialog (Win + R), type `services.msc` and press Enter.
- Scroll down to find 'Print Spooler'. Right-click and select 'Stop'.
- Open File Explorer and navigate to: `C:\Windows\System32\spool\PRINTERS`
- Delete all files inside this directory (requires administrator access).
- Return to Services window, right-click 'Print Spooler' and select 'Start'.

Step 3: Remove and Re-add Printer
- Go to Settings > Devices > Printers & Scanners.
- Click on your printer and choose 'Remove device'.
- Click 'Add a printer or scanner' and select your printer from the auto-discovered list or enter its network IP address.

Step 4: Set as Default Printer
- In Printers & Scanners settings, uncheck 'Let Windows manage my default printer'.
- Click your printer -> Manage -> Set as default.

Step 5: Print Test Page
- In Printer Properties, click 'Print Test Page'. If the test page prints, the issue was software queue obstruction.
