=== Application Crash & Software Repair Guide ===

Problem Overview:
Desktop applications (e.g. Teams, Excel, Chrome, proprietary tools) crash on startup, freeze, or display DLL / missing runtime errors.

Step 1: Force Close Unresponsive Application
- Press Ctrl + Shift + Esc to open Task Manager.
- Locate the frozen process under the 'Processes' tab.
- Click 'End Task'.

Step 2: Run Application in Safe Mode / Repair Mode
- For Microsoft Office Apps:
  - Hold Ctrl while opening the app icon, or press Win + R and type `excel /safe` or `winword /safe`.
- Repair Microsoft Office:
  - Go to Settings > Apps > Installed Apps.
  - Locate Microsoft 365 / Office -> click Modify -> select 'Quick Repair'.

Step 3: Clear Application Cache Data
- Microsoft Teams: Close Teams. Press Win + R, type `%appdata%\Microsoft\Teams` and delete all contents inside the cache folders (`Cache`, `blob_storage`, `databases`, `GPUcache`).
- Web Browsers: Reset browser settings to default or run in Incognito mode without extensions.

Step 4: Verify Runtime Dependencies
- Ensure Microsoft Visual C++ Redistributable packages and .NET Framework are up-to-date.
- Check Windows Event Viewer (Win + R -> `eventvwr.msc` -> Windows Logs -> Application) to identify specific faulting module DLL files.

Step 5: Reinstall Software with Administrator Rights
- Uninstall software via Settings > Installed Apps.
- Restart computer.
- Right-click installer file and choose 'Run as administrator'.
