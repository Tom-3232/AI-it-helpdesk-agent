=== Slow Laptop & High System Resource Usage Guide ===

Problem Overview:
Laptop is running very slow, high CPU or RAM usage (90%+), system freezing, or fan running at maximum speed.

Step 1: Check Task Manager Resource Usage
- Press Ctrl + Shift + Esc to open Task Manager.
- Sort processes by CPU, Memory, and Disk usage to identify resource-hogging background tasks.
- If System Interrupts or Antivirus Scans are using 100% CPU, allow 10-15 minutes for automated background indexing/scanning to complete.

Step 2: Disable Unnecessary Startup Apps
- In Task Manager, switch to the 'Startup Apps' tab.
- Select heavy non-essential programs (e.g. Spotify, Discord, Steam, OneDrive sync) and click 'Disable'.
- Reboot system.

Step 3: Perform Disk Cleanup & Remove Temporary Files
- Press Win + R, type `cleanmgr` and press Enter. Select drive C: and check 'Temporary Files', 'Recycle Bin', and 'System Cache'. Click OK.
- Clear User Temp files: Win + R -> `%temp%` -> Select all files (Ctrl + A) and delete. Skip files currently in use.

Step 4: Check Storage Space & SSD Health
- Ensure Drive C: has at least 15-20% free disk space available. Solid State Drives (SSDs) suffer severe performance degradation when full.

Step 5: Run Windows System File Checker & DISM
- Open Command Prompt as Administrator.
- Execute: `sfc /scannow`
- If corrupted files are found, execute: `DISM /Online /Cleanup-Image /RestoreHealth`
- Reboot after scan completes.

Step 6: Power Plan & Thermal Inspection
- Go to Settings > System > Power & Battery. Ensure Power Mode is set to 'Best performance'.
- Ensure laptop air vents are clean and unblocked to prevent thermal throttling.
