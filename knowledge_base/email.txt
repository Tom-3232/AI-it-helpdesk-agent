=== Email & Microsoft Outlook Troubleshooting Guide ===

Problem Overview:
Outlook hangs on 'Processing', stuck in disconnected state, cannot send/receive emails, or prompts repeatedly for password.

Step 1: Check Outlook Connection Status
- Look at the bottom status bar in Outlook:
  - If it says 'Disconnected' or 'Trying to connect', verify your network connection and corporate VPN.
  - Hold Ctrl key and right-click the Outlook icon in system tray -> select 'Connection Status' to check Exchange server response time.

Step 2: Launch Outlook in Safe Mode
- Press Win + R, type `outlook.exe /safe` and press Enter.
- Select your default profile. If Outlook opens normally in Safe Mode, a faulty COM add-in is causing the crash:
  - Go to File > Options > Add-ins.
  - Select 'COM Add-ins' -> click Go. Uncheck non-essential add-ins (e.g. anti-virus add-ins, third-party plugin extensions).

Step 3: Rebuild Outlook OST Profile Cache
- Close Outlook.
- Go to Control Panel > Mail (Microsoft Outlook) > Data Files.
- Select your `.ost` file path and click 'Open File Location'.
- Rename the `.ost` file to `.ost.old`.
- Restart Outlook. Outlook will automatically re-create the `.ost` file and resynchronize your mailbox from the Exchange cloud server.

Step 4: Repair Office Installation
- Open Windows Settings > Installed Apps.
- Search for Microsoft 365 Apps -> click Modify -> select 'Online Repair'.

Step 5: Verify Webmail Access (OWA)
- Log into Outlook Web App (https://outlook.office.com). If webmail works, the issue is isolated to your local client software installation.
