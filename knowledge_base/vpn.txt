=== Corporate VPN Connection Troubleshooting Guide ===

Problem Overview:
VPN connection fails to establish, disconnects frequently, or shows authentication errors (e.g. Cisco AnyConnect, GlobalProtect, OpenVPN).

Step 1: Check Internet Connection Baseline
- Disconnect VPN. Ensure your baseline Wi-Fi or Ethernet internet connection is working properly by browsing a public web page.

Step 2: Verify Gateway Server Address & Credentials
- Open your VPN client software.
- Confirm the gateway URL is correct (e.g., `vpn.company.com` or `gateway.corp.com`).
- Re-enter your corporate username and password accurately.

Step 3: MFA / Authenticator Notification
- Upon entering credentials, approve the push notification on your mobile Authenticator app immediately (within 60 seconds).
- If using TOTP code, append the 6-digit passcode if prompted.

Step 4: Restart VPN Agent & Network Adapter
- Right-click the VPN client tray icon and select 'Exit'.
- Open Task Manager, kill any leftover VPN processes (e.g. `vpnagent.exe` or `PanGPS.exe`).
- Open Command Prompt as Administrator and restart the service:
  - `net stop vpnagent`
  - `net start vpnagent`

Step 5: Check TAP/TUN Virtual Adapter
- Go to Device Manager (Win + X -> Device Manager).
- Expand 'Network adapters'. Ensure the Virtual VPN adapter (e.g. Cisco AnyConnect Secure Mobility Client Virtual Miniport) is enabled.

Step 6: Avoid Double VPN / Hotspot Conflicts
- Ensure you are not connected to another personal VPN software simultaneously.
- If using mobile hotspot, ensure your mobile carrier allows VPN pass-through protocols (IPsec/L2TP/SSL).
